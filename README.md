# Python Password Checker and Generator

A simple Python program that allows users to either:

- Check the strength of an existing password
- Generate a random password
- Choose how many letters, numbers, and symbols are included

## Features

- Password strength scoring
- Checks password length
- Checks for letters, numbers, and symbols
- Random password generation
- Randomizes generated password characters
